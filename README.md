# استخراج مقالات سیویلیکا

یک ابزار فارسی و مستقل برای گرفتن فهرست مقاله‌های صفحهٔ عمومی پژوهشگر در
[Civilica](https://civilica.com)، انتخاب موارد دلخواه و دریافت فایل Word راست‌چین.

این پروژه عمداً در ریپوی جدا از ScholarPulse قرار دارد.

## امکانات نسخهٔ فعلی

- دریافت لینک صفحهٔ پژوهشگر با یک درخواست.
- استخراج عنوان، نوع مقاله، سال، محل انتشار و لینک هر مقاله.
- جست‌وجو و فیلتر مقاله‌ها قبل از خروجی.
- صفحه‌بندی فهرست‌های بزرگ، 12 مقاله در هر صفحه.
- انتخاب همه یا چند مقاله.
- انتخاب سبک ارجاع APA 7th، Vancouver، IEEE، Harvard، Chicago، MLA 9th یا BibTeX.
- دریافت فایل Word استاندارد `.docx` یا فایل سازگار قدیمی `.doc`.
- داخل Word: فارسی با B Nazanin اندازهٔ 14 و انگلیسی با Times New Roman اندازهٔ 13.
- متن Word راست‌به‌چپ و راست‌چین است و عددهای متن، سال‌ها و شماره‌های ارجاع با Times New Roman اندازهٔ 13 نمایش داده می‌شوند؛ رقم‌های داخل لینک هم تغییر نمی‌کنند.
- امکان افزودن یا حذف لینک مقاله‌های سیویلیکا از فایل Word.
- نمایش آواتار پایدار پژوهشگر با Jdenticon، حتی وقتی تصویر واقعی در دادهٔ عمومی موجود نباشد.
- حالت جایگزین برای چسباندن HTML صفحه، وقتی سرور عمومی توسط Civilica محدود شود.
- بدون API key، سرویس هوش مصنوعی یا اطلاعات کارت بانکی.

## اجرای محلی در ویندوز

1. این پوشه را باز کنید.
2. روی start.bat دوبار کلیک کنید.
3. مرورگر را روی http://127.0.0.1:5000 باز کنید.

یا از PowerShell:

~~~powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
~~~

## روش استفاده

1. آدرس صفحه‌ای مانند https://civilica.com/p/176225/ را وارد کنید.
2. مقاله‌ها را بررسی و انتخاب کنید.
3. سبک ارجاع و نوع فایل Word را انتخاب کنید.
4. در صورت نیاز افزودن لینک مقاله‌های سیویلیکا را خاموش کنید.
5. روی «دریافت فایل Word» بزنید.

`.docx` فایل واقعی و استاندارد امروزی Word است. گزینهٔ `.doc` برای برنامه‌ها یا گردش‌کارهای قدیمی‌تر ارائه شده و به‌صورت Word-compatible تولید می‌شود.

اگر مرحلهٔ اول با خطای دسترسی روبه‌رو شد، در همان صفحه بخش «اگر دسترسی مستقیم بسته بود»
را باز کنید، کد HTML صفحه را با گزینهٔ View Page Source کپی و پردازش کنید.

## نکتهٔ فنی و حریم استفاده

خروجی فعلی اطلاعاتی را می‌سازد که در فهرست نمایه‌شدهٔ صفحهٔ پژوهشگر دیده می‌شود؛
PDF یا متن کامل مقاله‌ها را دانلود نمی‌کند. سایت Civilica ممکن است درخواست‌های
خودکار از سرورهای عمومی را محدود کند، بنابراین این ابزار برای استفادهٔ کم‌حجم و
پژوهشی طراحی شده است و راهی برای دور زدن محدودیت‌های سایت ارائه نمی‌دهد.

صفحهٔ خلاصهٔ پژوهشگر معمولاً نام همهٔ نویسندگان هر مقاله را ارائه نمی‌کند. در چنین حالتی
نام پژوهشگر پروفایل به‌عنوان نویسندهٔ جایگزین در citation قرار می‌گیرد و باید قبل از
استناد نهایی با صفحهٔ مقاله یا PDF بررسی شود.

برای اجرای محلی هیچ هزینه‌ای لازم نیست. اگر بعداً نسخهٔ عمومی روی یک سرویس میزبانی
منتشر شود، شرایط و محدودیت پلن رایگان همان سرویس باید جداگانه بررسی شود؛
GitHub Pages به‌تنهایی Python API این پروژه را اجرا نمی‌کند.

این ابزار توسط [سهیل آقایانی](https://github.com/Soheil-Aghayani/CivilicaPulse.git) طراحی شده است.
